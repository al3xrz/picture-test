# Работа с админкой

Админка доступна по адресу `/admin`. Доступ защищён HTTP Basic — логин и
пароль берутся из переменных окружения `ADMIN_USER` и `ADMIN_PASSWORD`.

## Вход

1. Откройте `/admin`.
2. Введите логин и пароль.
3. Креды сохраняются в `sessionStorage` браузера только на текущую сессию
   (закрытие вкладки очищает их). Кнопка выхода в правом верхнем углу
   очищает их принудительно.

> В продакшене nginx терминирует HTTPS — тогда Basic-заголовок передаётся по
> защищённому соединению.

## Список вопросов

- Таблица с миниатюрой, ссылкой, числом вариантов и правильным ответом.
- **Поиск** фильтрует вопросы по тексту вариантов ответа.
- Кнопка **Обновить** перезапрашивает данные, иконка выхода — завершает сессию.
- Счётчик вверху показывает общее число вопросов.

## Создание и редактирование

Кнопка **Добавить** (или иконка карандаша в строке) открывает диалог:

1. **Изображение** — вкладки:
   - **Загрузить** — drag&drop или клик для выбора файла (JPG/PNG/WEBP/GIF/SVG,
     до `MAX_UPLOAD_MB`). После загрузки показывается превью; можно заменить
     или очистить.
   - **URL** — вставьте внешнюю ссылку, превью появится сразу.
2. **Варианты ответа** — строки с текстом. Радио-кнопка слева отмечает
   правильный вариант. Кнопка **Добавить** добавляет вариант, корзина удаляет
   (минимум 2). Правильный ровно один.
3. **Порядок** — числовая позиция вопроса (`0` = в конец).

Нажмите **Сохранить**. Ошибки валидации подсвечиваются в диалоге.

## Удаление

Иконка корзины → подтверждение. Если изображение было загружено локально,
файл из `uploads/` также удаляется. Действие необратимо.

## Правила валидации

| Правило                         | Проверяется где        |
| ------------------------------- | ---------------------- |
| Изображение обязательно         | клиент + бэкенд        |
| ≥ 2 варианта                    | клиент + бэкенд        |
| Ровно один правильный           | клиент + бэкенд        |
| Непустой текст варианта         | клиент + бэкенд        |
| Допустимый тип и размер файла   | бэкенд                 |
